# 4 Grafikk, brukergrensesnitt og animasjon — oppsummering

Tegning med tkinter (uke 49), bevegelse og simulering på rutenett (uke 50), taster, klikk og knapper (uke 51), og spill med klasser og kollisjon (uke 1).

Kapittelet bygger på klasser fra kapittel 2. Hver ting som beveger seg, er et objekt som vet hvor det er og kan tegne seg selv. Det er akkurat det simuleringsoppgaven på eksamen ber om.

Hvert tema har en typisk oppgave nederst. Prøv selv før du åpner løsningen. **På eksamen** viser hvilke eksamensoppgaver som tester temaet.

tkinter følger med Python, så du trenger ikke installere noe.
